Tool Caller Demo

The Tool Caller is an Agent that automatically determines which function to call based on your prompt. It analyzes your request and selects the most appropriate tool from its available options.

In this demo, the Tool Caller has access to two functions:

  • getWeather: Gets the weather for a specified location
  • getTime: Gets the current time for a specified location

Try asking about the weather or time in different locations, or use the preset buttons below!
